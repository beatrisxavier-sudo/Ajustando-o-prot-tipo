# 🚀 Registro de Aprendizados — Teste de Usabilidade do Protótipo

Este repositório contém a documentação e uma interface web interativa dedicada a registrar as **reflexões e aprendizados obtidos após o teste de usabilidade do nosso protótipo**, conduzido em colaboração com outro time do projeto.

---

## 📌 Visão Geral do Projeto

Durante a sessão de validação do protótipo com usuários do outro time, focamos em observar o comportamento natural, dúvidas e reações espontâneas. A partir dessas observações, registramos dois aprendizados centrais no documento do projeto.

---

## 💡 Aprendizados Principais

### 1. 🔍 Dúvida/Organização: Navegação Inicial
* **O que aconteceu:** Ao abrir o protótipo, o usuário hesitou sobre qual botão ou opção acionar primeiro para concluir a tarefa.
* **Aprendizado:** A hierarquia visual da tela inicial precisa ser reorganizada. É crucial dar maior destaque visual (contraste, posicionamento e chamadas mais claras) para o fluxo primário.

### 2. 💎 Valor Percebido: Painel de Resumo Rápido
* **O que aconteceu:** O usuário elogiou espontaneamente o quadro de resumo, mesmo que a nossa equipe o considerasse apenas um recurso secundário.
* **Aprendizado:** O recurso resolve uma dor importante de agilidade para o usuário. Ele será promovido a uma das funcionalidades centrais do aplicativo nas próximas iterações.

---

## 🛠️ Tecnologias Utilizadas nesta Aplicação Web

* **HTML5:** Estrutura semântica e acessível.
* **CSS3:** Tema escuro (Dark Mode) moderno com efeitos de *glassmorphism*, variáveis CSS e flexbox/grid layout.
* **JavaScript (Vanilla):** Sistema interativo para expansão de cards e filtragem dinâmica de feedback.
* **Font Awesome:** Ícones vetoriais integrados.
